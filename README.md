# AlgoViz

AlgoViz is a fully local, hostable algorithm visualizer scaffold. This repository currently contains the monorepo structure, workspace configuration, Docker placeholders, and Catppuccin Mocha design tokens that future feature phases will build on.

## Development

```sh
make dev
```

This starts the Vite app workspace during the bootstrap phase.

## Docker

```sh
make up
```

Docker Compose currently uses placeholder images until the app and tracer are implemented.
